# Amy Publisher

Amy Publisher is a private tool built and used by one person, Keshav Gupta (Instagram @staykarping). It is not a public service.

## Terms of Service

Amy Publisher is for personal use by its owner only. It posts the owner's own videos to the owner's own accounts, and only after the owner approves each post. No one else can use it or sign up for it.

## Privacy Policy

Last updated 25 October 2026.

### What the app does

Amy Publisher uploads videos that its owner has made to the owner's own YouTube channel, Instagram, Facebook Page, TikTok and LinkedIn accounts. It does this only when the owner approves a post.

### What it accesses

Through each platform's sign-in, it asks for permission to upload videos and captions to the owner's own account and to read the account name to confirm the connection. For TikTok this is Login Kit (user.info.basic) and the Content Posting API (video.publish, video.upload). It does not read other people's data, messages, comments or email.

### What it stores

A sign-in token for each platform is stored in a file on the owner's own computer. Nothing is sent to any server run by the app. Videos and captions are stored on the owner's computer only.

### Sharing

Data is not sold, shared or used for advertising. It is sent only to the platform the owner chose to post on, to carry out that post.

### Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

### Removing access

Access can be removed at any time in each platform's app permissions settings, for example myaccount.google.com/permissions for Google, or the TikTok app's security and permissions settings. Deleting the sign-in file on the owner's computer also ends access.
